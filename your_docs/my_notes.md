# Personal Learning Notes: Weeks 1 to 5

## Week 3 & 4: Function Calling and AI Agents
* Function calling allows an LLM to produce structured JSON parameters to execute real Python functions.
* Agents use function calling in a loop to perform tool-assisted tasks like web search, database querying, and data analysis.

## Week 5: Vector Databases, RAG, and Transformers
* RAG stands for Retrieval-Augmented Generation.
* The Transformer architecture relies heavily on attention mechanisms to process sequences in parallel, which is the same foundation used by modern LLMs like Gemini.
* Grounding system prompts prevent model hallucinations by explicitly telling the LLM to answer only from provided context chunks.
